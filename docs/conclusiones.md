# Conclusiones Personales — Examen Práctico Integrador IoT 3.1

La integración de este proyecto demostró la viabilidad de enlazar una arquitectura en la nube con un sistema electromecánico en tiempo real, conectando Swagger UI (HTTPS) y una API en FastAPI desplegada en AWS EC2 vinculada a Amazon RDS MySQL. El uso de WebSocket Seguro (WSS) fue determinante para recibir órdenes instantáneas sin sobrecargar la red mediante consultas periódicas (polling), logrando una correspondencia exacta entre cada petición remota y la excitación de los 12 canales de actuación mediante dos registros de desplazamiento 74HC595 en cascada y optoacopladores que mantuvieron aislado eléctricamente el control remoto de la excavadora.

El principal reto técnico y aprendizaje se centró en la robustez y seguridad del firmware en el ESP32, donde se implementó una lógica 100% no bloqueante con temporizadores basados en `millis()`. Esto permitió garantizar la auto-liberación de pulsos, exclusión mutua entre movimientos incompatibles (como avance y reversa simultáneos) y el pase automático a estado seguro ante pérdidas de conexión. Asimismo, el descarte de órdenes históricas durante la reconexión evitó movimientos involuntarios, mientras que la integración de WiFiManager otorgó total autonomía y portabilidad al vehículo para conectarse a cualquier red sin exponer credenciales en el código fuente.
